Sistem web otomatisasi pelatihan internal dan pembaruan UI/UX website resmi instansi berbasis Laravel, dirancang khusus untuk meningkatkan efisiensi operasional manajemen pemerintah dan mempercepat akses informasi bagi publik.

Context & Problem

Selama menjalani program magang di instansi pemerintahan di bawah Kementerian Komdigi, pencatatan kegiatan pelatihan dan manajemen operasional pegawai masih konvensional, sehingga berisiko tinggi terhadap kehilangan data dan lambatnya rekapitulasi laporan. Selain itu, website resmi instansi memerlukan perbaikan mendesak karena UI yang kurang profesional dan UX yang belum adaptif bagi publik.

Engineering Approach

Memadukan kerangka modern dengan pemodelan fungsional. Sistem internal dibangun menggunakan Laravel dan MySQL (local server XAMPP dengan version control Git) mulai dari analisis kebutuhan, perancangan database, hingga implementasi otomatisasi rekapitulasi. Untuk redesign website instansi, fokus diarahkan pada perombakan struktur tata letak responsif, adaptif, dan navigasi UI/UX yang intuitif.

Results & Impact

  • ✓ Efisiensi & Keamanan Data: Mengotomatisasi pencatatan pelatihan internal, memangkas rekapitulasi manual, serta memusatkan manajemen operasional secara aman.
  • ✓ Optimalisasi Aksesibilitas Publik: Berhasil merombak total website resmi instansi dengan UI profesional serta UX yang cepat dan adaptif bagi masyarakat.
  • ✓ Standar Teknis Modern: Implementasi kerangka kerja Laravel & MySQL (didukung Git & XAMPP) yang memastikan kestabilan dan keandalan sistem secara keseluruhan.
