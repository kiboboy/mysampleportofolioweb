Sistem Pelayanan Masyarakat Berbasis Web

Sistem e-Government berbasis web dengan arsitektur multi-peran (Citizen, Admin, dan Executive Dashboard) yang dirancang untuk mendigitalisasi alur birokrasi, mempercepat layanan administrasi surat-menyurat dan pengaduan masyarakat secara real-time, serta mengoptimalkan pengarsipan digital.

Technologies & Tools Used

PHP MySQL HTML / CSS / JS Tailwind / Bootstrap Git & GitHub Figma Framer VS Code

Context & Problem

Sebelum sistem ini dikembangkan, seluruh proses pelayanan administrasi kependudukan, pengajuan surat (seperti SKTM, Domisili, SKU), serta penanganan pengaduan masyarakat masih konvensional dan terfragmentasi. Warga harus antre, arsip dikelola manual (rentan hilang & human error), serta Wali Nagari kesulitan memantau performa pelayanan secara instan.

Engineering Approach

Saya merancang arsitektur berbasis peran (multi-role access control) yang memisahkan akses untuk warga, admin, dan pimpinan eksekutif. Backend dikembangkan dengan PHP (Laravel) & MySQL, mendukung modul self-service, real-time status tracker, sistem validasi berjenjang, dan pelaporan (PDF/Excel) untuk Executive Dashboard. Antarmuka dipastikan responsif lintas perangkat.

Results & Impact

  • ✓ Digitalisasi Birokrasi Komprehensif: Mentransformasi pelayanan manual menjadi terpusat, memangkas antrean, dan mengeliminasi risiko kehilangan arsip fisik.
  • ✓ Transparansi & Kecepatan Layanan (Real-Time Tracking): Warga dapat mengajukan berbagai dokumen penting dan melacak statusnya secara real-time tanpa batasan waktu.
  • ✓ Optimalisasi Kinerja Perangkat & Eksekutif: Mempermudah verifikasi dokumen berjenjang dan menghadirkan Executive Dashboard untuk pantauan performa instan bagi Wali Nagari.
